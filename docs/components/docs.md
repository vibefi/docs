`docs/` contains VibeFi's Docusaurus documentation site (this site).

## Stack

- Docusaurus
- TypeScript
- Bun package manager/scripts
- Cloudflare Pages deployment target

## Local Run

```bash
cd docs
bun install
bun start
```

## Build

```bash
cd docs
bun run build
bun run serve
```
