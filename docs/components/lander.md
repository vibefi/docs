title: Lander
---

`lander/` is the public-facing landing page for VibeFi.

## Stack

- React + TypeScript + Vite
- Bun package manager/scripts
- Cloudflare Pages deployment target

## Local Run

```bash
cd lander
bun install
bun run dev
```

## Build

```bash
cd lander
bun run build
bun run preview
```
